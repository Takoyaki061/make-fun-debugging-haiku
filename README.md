A program that writes one haiku about debugging to `/output/entry.txt` — seventeen syllables in 5-7-5 form:

> A stack trace points north
> I chase it down through the dark
> it points back at me

The trace points away, the chase leads through the dark, and the last line turns it back on the debugger.

## Run it

```sh
python3 main.py
```
